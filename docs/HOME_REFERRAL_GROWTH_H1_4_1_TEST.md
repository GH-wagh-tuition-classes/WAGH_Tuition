# H1.4.1 Live Test Checklist

1. Log in as an active Student.
2. Open **Refer & Grow**.
3. Confirm the status changes from `Preparing your referral link…` to `Your referral dashboard is ready.`
4. Confirm a code beginning with `WTC-` appears.
5. Confirm the personal link contains `source=referral`, `campaign=student-referral`, and the same referral code.
6. Test Copy, WhatsApp, Share Link, and Refresh.
7. Refresh the browser while the Referral section is open; confirm it restores and loads automatically.
8. Open the referral link in an incognito window and verify the invitation banner appears.
9. Confirm Student Assigned Tests, Progress, Daily Challenge, Teacher Dashboard, and Admin Dashboard still load.
10. Confirm no Apps Script redeployment was needed.
